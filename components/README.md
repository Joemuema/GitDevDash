# `components/` — Feature components by domain

Presentational React components grouped by product area. Layout and page
furniture live in `layout/`; the reusable Base UI primitive library lives in
`ui/` and is imported by every other folder here.

## Subfolders

- `auth/` — Sign-in sheets, account menus, session provider and notices.
- `favorites/` — Saved-developer list, toolbar and provider.
- `layout/` — App shell, sidebar, header, footer, backdrop, page containers.
- `match/` — Job-match presentation: intake forms, match cards, shortlist
  table, tips panel, saved roles, share actions.
- `onboarding/` — First-visit questionnaire flow and its display gate.
- `profile/` — Developer profile header, stats, analytics and repo displays.
- `repo/` — Repository detail header, facts, language breakdown, file tree.
- `search/` — Search hero, form, filters, result cards and pagination.
- `settings/` — Account and preference forms for the settings page.
- `shared/` — Cross-domain bits: breadcrumbs, external links, favorite toggle.
- `ui/` — The 34-primitive Base UI component library (buttons, dialogs,
  tables, charts, sidebar, questionnaire…).
